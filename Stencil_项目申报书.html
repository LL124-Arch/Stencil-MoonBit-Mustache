第八届 CCF 开源创新大赛 - 选题申报书

项目名称：Stencil - 基于 MoonBit 的轻量级高性能原生模板引擎

参赛方向：生态库移植；参考规范：Mustache 官方核心规范；许可证：MIT

仓库： GitHub · GitLink · Mooncakes

选题背景与价值

Stencil 完全采用 MoonBit 原生实现 Mustache 风格模板引擎，零外部运行时依赖，支持 WASM、WASM-GC、JS 和 Native，面向页面、邮件、配置片段、边缘函数和结构化文本生成场景。

核心功能

  1. {{var}} 默认 HTML 转义，支持三括号和 {{&var}} 原始输出。
  2. 支持布尔值、数字、字符串、对象、数组、隐式迭代、嵌套作用域、点号路径和反转区块。
  3. 支持 comments、standalone 控制行、partial 智能缩进、nested partial 和默认分隔符下的 CRLF 输入。
  4. 支持 {{=<% %>=}}<%name%> 可变分隔符。
  5. 对未闭合标签、区块错配、无效分隔符、超深 section 和超深 partial 提供可诊断错误。

lambda、表达式求值、文件系统 partial 加载和动态 partial 名称暂不属于当前范围，具体支持子集与边界见 Mustache 兼容性说明。

系统架构

  1. Scanner：游标扫描，不依赖正则，支持标签和分隔符切换。
  2. Parser：递归下降构建 AST，并限制最大 section 嵌套深度。
  3. Context：上下文栈实现嵌套作用域、父级回退和点号路径。
  4. Render：AST 深度遍历与 StringBuilder 输出，默认安全转义并限制 partial 展开深度。

工程质量与验证

项目包含 246 个确定性测试，覆盖兼容性、错误、Unicode、CRLF、长文本、深层嵌套、大列表、partial、可变分隔符和递归边界；新增 TemplateCatalog 命名模板目录、依赖图、健康报告和批量渲染管线，可用于页面、邮件、配置和文档生成；CI 执行格式检查、严格类型检查、接口生成检查、多目标构建和 WASM/JS/Native 测试；基准脚本记录编译后重复渲染、批量报告和 CLI 端到端数据。
