一、 选题背景与意义

痛点： 随着 WebAssembly (WASM) 技术的普及，MoonBit 凭借其编译速度与运行时性能备受瞩目。然而，目前官方生态 (mooncakes.io) 中依然缺乏一个生产可用的原生模板引擎，导致 Web 开发中动态页面生成极为不便，削弱了开发体验。

价值： 本项目旨在填补该空白，完全采用 MoonBit 原生开发 Mustache 风格的模板引擎。它零外部依赖，直接编译成 WASM，具有超小体积和极致性能，完美适用于 Serverless 计算与边缘渲染。

二、 核心功能

本项目遵循 Mustache 逻辑分离语法，提供以下完整功能：

  1. 安全插值与防 XSS： 默认自动对 {{var}} 进行 HTML 实体转义，同时支持三括号 {{{var}}} 原始输出。
  2. 多态区块渲染： 根据 JSON 数据类型自动派发渲染逻辑。支持 {{#section}} 条件判断、隐式列表迭代以及作用域潜入。
  3. 反转区块处理： {{^section}} 能够精准处理 null、false、空数组及空字符串等假值场景。
  4. 局部模板复用 ({{>partial}})： 支持模板互相嵌套，自带智能缩进对齐引擎，确保最终输出格式美观。
  5. 内联注释支持： 提供 {{!comment}} 机制标识开发说明，引擎自动忽略。

三、 系统架构设计

Stencil 遵循编译原理标准流程，由四大核心模块解耦构成：

  1. 滑动窗口 Scanner： 摒弃正则，基于双指针游标算法快速提取标签，实现极低 GC 负担。
  2. 递归下降 Parser： 将词法流转换为层次分明的抽象语法树 (AST)，遇错时利用最新 raise 机制精准抛出。
  3. 双端求值 Context： 采用栈式数据管理器，支持以点号（.）分隔的多级路径深层查找。
  4. 深度遍历 Render： 结合 AST 与上下文栈，利用 StringBuilder 实现高速渲染和自动化缩进铺平。

四、 核心技术优势

  1. 纯正多包架构： 采用高级的 src (核心库) 与 cli (终端应用) 分包设计，代码结构远比扁平铺设更具扩展性和工业水准。
  2. 现代化类型安全： 全面应用 MoonBit 新引入的 suberror 异常流，杜绝栈溢出等解析风险，安全可靠。
  3. 高质量工程沉淀： 内置 30 余个高覆盖率测试用例（moon test 全绿），全部代码经 moon fmt 严格约束，展现出优秀的开源标准。
